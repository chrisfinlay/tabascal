**T**r**A**jectory **BA**sed RFI **S**ubtraction and **CAL**ibration (TABASCAL)
of radio interferometry data. A source-to-visibility model for astronomical and
RFI sources including near-field effects, in which visibility data is jointly
calibrated and cleaned of specific RFI contamination by modelling the RFI signal
in the visibilities.

Development moved to [epfl-radio-astro/tabascal](https://github.com/epfl-radio-astro/tabascal),
which is the official and only maintained home of the project. Nothing in this
repository is supported, and the instructions it once contained are obsolete.

## Historical note

This repository holds the pre-2025 TABASCAL codebase. Its source, documentation
and installation instructions are kept only for the historical record and remain
available in the git history and in the file tree of this repository — **they are
obsolete and must not be followed.** For anything current, go to
[epfl-radio-astro/tabascal](https://github.com/epfl-radio-astro/tabascal).
